# Итоговый проект по курсу «Инженерия Искусственного Интеллекта»

В этой папке находится итоговый мини-проект по курсу.  
Проект демонстрирует применение методов и инструментов инженерии ИИ: работу с данными, модели, пайплайны, сервис, эксперименты и воспроизводимость.

- **Краткое описание (2-4 предложения):**  
  Проект посвящён построению сервиса для оценки вероятности дефолта по кредитной заявке.  
  Используется синтетический датасет, модели машинного обучения (Logistic Regression, Random Forest, XGBoost).  
  Результат – REST API (FastAPI), который по характеристикам клиента возвращает вероятность дефолта, категорию риска и рекомендацию.

## 2. Структура проекта

Проект организован в следующей структуре:

- `requirements.txt` – зависимости проекта (библиотеки Python, необходимые для запуска).
- `report.md` – отчёт по проекту (постановка задачи, данные, эксперименты, результаты).
- `self-checklist.md` – чеклист самопроверки проекта перед сдачей.
- `notebooks/` – экспериментальные ноутбуки:
  - `01_eda_and_experiments.ipynb` – разведочный анализ данных и сравнение моделей.
- `src/` – основной код проекта:
  - `src/data/load_data.py` – загрузка и предобработка данных;
  - `src/models/train.py` – обучение и сравнение моделей;
  - `src/service/app.py` – FastAPI сервис.
- `artifacts/` – сохранённые модели:
  - `credit_risk_model.pkl` – обученная модель XGBoost;
  - `preprocessor.pkl` – пайплайн предобработки.
- `configs/` – конфигурационные файлы:
  - `.env.example` – шаблон переменных окружения.
- `tests/` – тесты:
  - `test_api.py` – тестирование API endpoints.
- `Dockerfile` – контейнеризация сервиса.

Структура соответствует базовой, дополнительных изменений нет.

## 3. Требования и установка

### 3.1. Требования

- Python >= 3.10
- Docker (опционально, для контейнеризации)

### 3.2. Установка окружения

```bash
# Перейти в папку проекта
cd project

# Создать виртуальное окружение (рекомендуется)
python -m venv .venv

# Активировать окружение:
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

# Установить зависимости
pip install --upgrade pip
pip install -r requirements.txt
Особенности установки:
Все зависимости указаны в requirements.txt. Дополнительных шагов не требуется.

4. Как запустить проект
4.1. Запуск обучения модели
bash
cd project
python src/models/train.py
После обучения модели сохраняются в artifacts/:

credit_risk_model.pkl – обученная модель XGBoost

preprocessor.pkl – пайплайн предобработки

4.2. Запуск сервиса (API)
bash
cd project
python src/service/app.py
Порт: 8000

Эндпоинты:

GET / – информация о сервисе

GET /health – проверка состояния (логгирование, загрузка модели)

POST /predict – предсказание вероятности дефолта

Тестирование работоспособности:

Через браузер (Swagger UI):

text
http://localhost:8000/docs
Через curl:

bash
curl -X POST "http://localhost:8000/predict" \
  -H "Content-Type: application/json" \
  -d '{
    "age": 35,
    "income": 50000,
    "loan_amount": 15000,
    "loan_duration": 36,
    "employment_years": 5,
    "credit_history": "good",
    "purpose": "car",
    "savings": 10000
  }'
4.3. Запуск с Docker
bash
cd project
docker build -t credit-risk-api .
docker run -p 8000:8000 credit-risk-api
5. Данные
Источник данных: Синтетический датасет (создаётся программно)

Где лежат файлы: Данные НЕ хранятся в репозитории. Генерация происходит автоматически в src/data/load_data.py

Описание данных:

Размер: 1000 записей

Признаки: возраст, доход, сумма кредита, срок кредита, стаж работы, кредитная история, цель кредита, сбережения

Целевая переменная: default (0 – нет дефолта, 1 – дефолт)

Распределение: сбалансированное (504 / 496)

Для воспроизведения результатов достаточно запустить python src/models/train.py – данные сгенерируются автоматически.
